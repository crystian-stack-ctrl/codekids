# CodeKids — Progression + Builder Terminal

## Launch locally
Open `index.html` in a modern browser.

## Update GitHub Pages
1. Open your CodeKids repository.
2. Choose Add file → Upload files.
3. Upload `index.html` and `README.md` from this folder to the repository root.
4. Commit changes to `main`. Existing GitHub Pages settings can remain unchanged.

## New feature: Builder Terminal
A safe, simulated terminal for young and advanced learners. Commands include `help`, `ls`, `pwd`, `about`, `cat README.md`, `run`, `date`, `whoami`, `echo`, and `clear`.
It does not execute arbitrary shell commands or access the learner's computer. The `run` command opens the existing beginner Practice playground.
