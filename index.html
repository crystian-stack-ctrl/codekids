🧠 Gifted coder missions

1. Navigate: pwd, ls, cd projects, cd ...

2. Create a folder and file: mkdir mission, cd mission, touch plan.txt.

3. Write and read: echo "Build a robot" > plan.txt, cat plan.txt.

4. Search and inspect: grep robot plan.txt, wc plan.txt, tree.

5. Use help for the full supported command list. This is a teaching simulator, not a complete Windows/Linux shell.
